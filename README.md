# LJT-Homepage

This repository contains the personal academic homepage of **Junteng Liu**, created from the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template and renamed as requested.

## Site structure

- **About / Home:** [`_pages/about.md`](_pages/about.md) contains the profile summary, academic background, research experience, skills and research interests, honors, contact profiles, and all six recorded publications.
- **Publications:** [`_pages/publications.html`](_pages/publications.html) renders the publication records in [`_publications/`](_publications/).
- **Navigation:** [`_data/navigation.yml`](_data/navigation.yml) exposes the existing About and Publications sections only.
- **Site and author settings:** [`_config.yml`](_config.yml) contains the repository deployment path and the contact/profile information recorded in memory.

## Profile summary

Junteng Liu is a first-year PhD candidate in the HKUST NLP Group at the Hong Kong University of Science and Technology. He graduated from Shanghai Jiao Tong University in June 2024. His research focuses on natural language processing and machine learning, including LLM reasoning and reinforcement learning, hallucination in vision-language models, and LLM truthfulness and interpretability.
